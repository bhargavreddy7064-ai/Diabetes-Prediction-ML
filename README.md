# Diabetes-Prediction-ML
Diabetes Prediction (ML &amp; SVM) End-to-end Python ML pipeline predicting diabetes onset using the Pima Indians dataset.  Features:  Preprocessing: Z-score feature scaling via StandardScaler.  Splitting: 80/20 train-test split stratified by target.  Classifier: Support Vector Machine (SVC linear kernel).  Stack: Python, Pandas, NumPy, Scikit-Learn.
